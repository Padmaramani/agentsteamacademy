Programs

Scratch

Developed by the MIT Media Lab, Scratch enables kids to build interactive stories, games, animations, and more, all by snapping together colorful code blocks that fit like puzzle pieces. This drag-and-drop approach removes the need to type complex code, making programming intuitive and error-free for beginners

Web development

  • HTML (HyperText Markup Language): HTML is the foundation of every website. It structures the content by organizing text, images, links, and other elements using special tags. Think of HTML as the skeleton of a web page
  • CSS (Cascading Style Sheets): CSS styles and beautifies the web page. It controls colors, fonts, layouts, and spacing, making websites visually appealing. CSS is like the clothes and decorations that dress up the HTML skeleton
  • JavaScript brings websites to life by adding interactivity and dynamic features. With JavaScript, kids can create games, interactive forms, animations, and more. It teaches logical thinking and problem-solving by letting them program how a website behaves

Python

Python is a powerful, easy-to-learn programming language that is widely used for everything from building websites and automating tasks to analyzing data and developing artificial intelligence. Its simple, readable syntax makes it especially popular among beginners and educators, as it allows new programmers to focus on learning core concepts without getting bogged down in complex code
